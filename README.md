# Personal Portfolio Website

## Overview

This repository contains my personal portfolio website, developed using HTML and CSS.

The website serves as a central hub where visitors can learn more about me, access my CV, view featured projects, and connect with me through LinkedIn, GitHub, and email.

The portfolio highlights my academic background, technical skills, certifications, and software engineering projects.

---

## Features

- Professional profile section
- About Me section
- Featured Projects showcase
- CV download button
- LinkedIn integration
- GitHub integration
- Email contact link
- Responsive design
- Modern glassmorphism user interface
- Animated gradient background

---

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)
